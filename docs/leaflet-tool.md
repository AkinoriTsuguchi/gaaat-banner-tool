# GAAAT リーフレット自動生成ツール（A4三つ折り）

[leaflet/index.html](../leaflet/index.html) / [leaflet/app.js](../leaflet/app.js)

バナーツールと同じ「案件シートの情報を差し替えるだけで版が出てくる」考え方で、
A4横・三つ折りのリーフレット（表裏2面）を組版するツール。バナーツールとは別の
ページとして `leaflet/` 以下に置いてあり、ロゴ（[leaflet/logo.js](../leaflet/logo.js)）と
OAuthクライアントIDだけを共有している。オリジンが同じなので、Google Cloud側の
追加設定は不要（`http://localhost:8934` などで一緒にホストすれば動く）。

要件から外したもの: **多言語対応と、会期ごと（都市ごと）の一括生成**。
リーフレットは会期をまたいで使い回す前提なので、言語タブも都市チェックリストも持たない。

## 折りの構造と面の対応

用紙を開いた面（内面）を左から C1 / C2 / C3 とすると、巻き三つ折りでは
C3 が C2 の上に、さらに C1 がその上に巻き込まれて畳まれる。したがって

- **内面（1ページ目）**: 左から C1 / C2 / C3 = 作品LISTの見開き
- **外面（2ページ目）**: 印刷面は左右が入れ替わるので 左から **C3 / C2 / C1**
  - C1 = 表紙（タイトル・会期・会場・ロゴ）
  - C2 = 裏表紙（GAAAT / Metal Canvas Art の説明）
  - C3 = 折り込み面（作品購入の仕方 + QR）

C3 は内側に巻き込まれるぶん細くする必要があるため、既定のパネル幅は
**99.5 / 99.5 / 98 mm**（`foldType: roll`）。均等に割りたい場合は 99 / 99 / 99 mm も選べる。
この対応関係は `panelRects()` に実装してあり、内面と外面で同じ関数から座標を出している。

## ECシートの読み込み

列の位置ではなく**見出しの文字**で列を判別する（`HEADER_ALIASES` / `buildColumnMap()`）。
案件によって列の数も並びも違うため、位置決め打ちだと使い回せないため。

- 「作品名」を含む行を見出し行とみなし、その下の行を作品として読む。
  1つのタブに表が複数あっても、見出し行を見つけるたびに対応表を差し替えるので通る。
- 「記入例→」の行は除外する。
- サイズ欄は1セルに作品サイズと額装サイズが同居しているケースがあるので、作品サイズ側だけを取る
  （`splitArtSize()`）。書き方が案件ごとに違うため、少なくとも次の2通りに対応している:
  「420（H）×297（W）mm [額装サイズ]533…」「作品サイズ：(H)841ｘ(W)547 額装外寸：(H)1147…」。
- `画像リンク（ドライブ）` 列が空でも、行のどこかにドライブの**ファイル**URLがあればそれを使う
  （`findDriveUrlInRow()`）。見出しが空欄の列（1行上に「URL」とだけ書かれたグループ見出しの下）に
  URLを置いている案件が実在し、見出し文字では引けないため。フォルダURLは拾わない。
- 読み直しても、掲載チェック・並び順・取得済み画像は作品名で引き継がれる（`applyArtworks()`）。
- `画像リンク（ドライブ）`（M列）は**URLとは限らない**。実際には「流れ星260814」「盲竜0803.png」の
  ようにファイル名や作品名＋日付だけのことが多い。URLならそこから直接取得し、そうでなければ
  ドライブフォルダ側の**ファイル名／サブフォルダ名**と突き合わせる（`findDriveFileByName()`）。
- サイズ欄の見出しは案件ごとに「作品サイズ：」「アート寸法：」があり、額装側も
  「額装サイズ」「額装外寸」の揺れがある。`splitArtSize()` で両方に対応済み。

読み込み口は2つあり、どちらも同じパーサー（`parseRows()`）を通る:
Googleログイン + スプレッドシートURL（`#gid=` 付きで対象タブを指定）と、範囲をコピーして貼り付け。

アクセストークンは1時間ほどで失効する。`googleApiFetch()` は 401 を受けたらトークンを捨てて
ログインボタンを押せる状態に戻す（`setSignedInUI(false)`）。以前はボタンが「ログイン済み」のまま
無効だったため、ページをリロードする＝入力内容を捨てる以外に復帰する方法がなかった。
再ログイン後は失敗した操作をユーザーがもう一度実行する（自動リトライはしない）。

## 作品画像

デザインデータは案件によって置き方が違い、フォルダ直下に全点並んでいることも、
**作品名ごとのサブフォルダに1点ずつ**入っていることもある（例: `シグルイ/デザインデータ/流れ星/*.tif`）。
`loadDriveFolder()` はサブフォルダを幅優先でたどり、各画像に「どのフォルダにあったか」(`folder`)を
持たせる。突き合わせはファイル名 → サブフォルダ名 → 作品名の順に緩めていく。
探索は `DRIVE_MAX_FOLDERS`（60）で打ち切る（フォルダが多い案件で待たされないため）。

**素材はデザインのみのデータを前提とする。** 額装や余白が写り込んだ物撮りは、ツール側で
切ったり枠を足したりせず、運用側でデザインデータに差し替えてもらう。以前は余白の自動トリムと
地色合わせを持っていたが、この前提に切り替えたため削除した。


`画像リンク（ドライブ）` 列がドライブのURLならそのファイルを直接取得する。
ファイル名だけが入っている案件が多いので、その場合は指定した**ドライブフォルダの一覧**から
ファイル名で突き合わせる（拡張子・全角半角・空白の揺れを吸収: `normalizeFileName()`）。
当たらなかった作品は、リストのサムネイルをクリックして個別にアップロードできる。

作品画像は**contain（余白を付けて全体を表示）** で描く。cover にすると作品がトリミング
されてしまうため、バナーツールと同じく原画は1pxも切らない方針。

## LIST面の見出し

既存リーフレット（R228_機動警察パトレイバー）に合わせ、左端パネルの頭を
「角のカギ括弧マーク → 大きなLIST → QR＋『ご購入はこちら』の囲み → 注意書き」の順に組む
（`drawListHeader()`、戻り値が作品グリッドの開始Y）。QRは以前は最終パネルの右下に置いていたが、
参照リーフレットに合わせて見出しの直下へ移した。注意書き
（「作品購入ページURLは、会期終了までSNS等に公開しませんようお願いいたします。」）は
毎回入れるものなので `qrListNote` の初期値として持たせてある。

## 作品カードの高さ計算

「載せる項目」の組み合わせと列数によって、カード内の文字の必要高さは大きく変わる。
画像の高さを固定比率で決め打ちすると、3列にしたときに文字が次の行のカードにかぶる。
そのため `buildCardPlan()` で**実際に折り返した行数まで含めて文字の高さを先に確定**し、
残りを画像に割り当てている。それでも入らない場合は、優先度の低い項目から順に落とす
（作品説明 → 画材 → エディション → サイズ → アーティスト名 → 作品番号。作品名と価格は必ず残す）。

行の高さには下限（列幅×1.15）を設けてあり、詰め込みすぎて版として使えなくなるのを防ぐ。
下限を切って入りきらない作品が出た場合は、**キャンバスではなく操作パネル側**に
「N件が入りきっていません」と出す（印刷データに警告文字が乗らないようにするため）。

## 書き出し

画面プレビューは軽さ優先で110dpi、書き出し時だけ選択したdpi（既定350）でオフスクリーンに
描き直す。レイアウト計算はすべてmm基準なので、dpiを変えても版は完全に一致する。

- PDF（jsPDF、CDN）: 1ページ目＝内面 / 2ページ目＝外面、塗り足し込みのページサイズ
- PNG: 内面・外面それぞれ

入稿時は「折り位置のガイド線」のチェックを外すこと（トンボは残してよい）。

## 固定文言と挿絵（外面）

「GAAAT / Metal Canvas Art とは」と「作品購入の仕方」は、案件が変わっても毎回同じものを刷る面なので、
入力欄ではなく `BOILERPLATE`（app.js）に和文・英文とも固定で持つ。画面には読み取り専用で表示するだけ
（`renderBoilerplatePreview()`）。文面・体裁は既存リーフレット `R222_syoyo_リーフレット_表（外）` に合わせた。

- 購入手順の挿絵3点は `leaflet/assets/howto-1〜3.png`。原本のPNGから等倍で切り出したもので、
  描き起こしではない。差し替えるときは同じ比率・白背景の線画にすること。
- 「How to buy」の見出しには緑のマーカー（`HIGHLIGHT_GREEN` = `#75BF71`、原本から実測）を敷き、
  右に和文見出しを小さく添える。
- 3ステップは面の高さいっぱいに均等配分する。先に各ブロックの高さを `wrapText()` で測り、
  余りを等間隔の空きに割り振っている。
- ステップ本文の級数（`jaSize` 3.8mm）は原本に合わせてある。小さくすると折り返し位置がずれて
  「スマートフォ／ン」のように語中で切れるので、安易に詰めないこと。
- GAAAT面は上端がロゴ画像＋タグライン、下端が web / EC / X / Instagram の4つのQR。
  QRのエンコード先は案件で変わりうるため画像は固定せず、アップロードされたスロットだけを詰めて並べる
  （`BRAND_QR_SLOTS`）。

## 表紙テンプレート

過去のリーフレット表紙を参照して4パターンに整理し、プルダウンで切り替えられるようにした
（`COVER_RENDERERS`）。共通部品（塗り足し矩形・ロゴ・コピーライト・字送りテキスト）はヘルパーに
寄せ、各テンプレートは「どこに何を置くか」だけを持つ。

| キー | 名称 | 参照元 | 構成 |
|---|---|---|---|
| `arch` | A アーチ額装型 | syoyo | 淡色地／上部に大型セリフのタイトル（センター）／アーチで抜いたキービジュアル／最下部に会期・会場 |
| `verticalJa` | C 和文縦組み型 | サイボーグ009 | 白地／作品を縦長で大きく／右にアクセント色の縦組みタイトル／下端中央にロゴ |
| `condensed` | E 大型コンデンス型 | ZEENCHIN | 淡色地／左上に極太の多段タイトル／下半分にキービジュアルをフルブリード／ロゴ右上 |
| `lockup` | F ロゴロックアップ型 | ウルトラマン | 白地／IPロゴ × GAAATロゴを縦に組む／片側にアクセントの縦バー／**作品画像を使わない** |

- **額縁・フレーム・アーチなどの装飾をツール側で描いてはいけない。** 支給素材には
  「デザインのみ / デザイン+額装 / 物撮り（余白あり）/ 物撮り（余白なし）」の4種類があり、
  どれが来るかは案件（監修で渡せるデータ）によって変わる。すでに額が写っている素材に
  こちらで枠を足すと額が二重になり、監修上の混乱を招く。初期実装にあったアーチ額装は
  この理由で撤去済み。
- **TIFFはブラウザが表示できない**（`<img src="*.tif">` は必ず onerror）。版元支給のマスターは
  1200dpiのTIFのことがあるので、UTIF（jsDelivr）でデコードしてCanvasに載せる（`decodeTiff()`）。
  そのままRGBA8に展開すると数百MBになるため、長辺 `TIFF_MAX_EDGE`（4200px≒A4長辺を約360dpi）
  まで縮めてから返す。ファイルアップロードとドライブ取得の両方が `loadImageFromBlob()` を
  通るので、片方だけ対応が漏れることはない。
- 素材差は装飾ではなく次の2つだけで吸収する:
  - `coverMatchBg`（既定ON）… `detectImageBackground()` で画像の地色を拾い、表紙全体に敷く。
    物撮りの地がグレーでも、切らずに馴染む。**地色は必ず元画像から拾うこと**。余白を詰めた
    画像は四隅が作品本体にかかっていて地色が読めず、白地に戻って残余白が箱状に見える。
  - `coverTrim`（既定ON）… `trimUniformMargin()` で一様な余白だけを落とす。作品には触れない。
    デザインのみの素材（絵柄が版面いっぱい）では何も削られないことを実素材で確認済み。
    ただし「白フチを意図して残したデザイン」は削ってしまうので、その場合はOFFにする。
- 縦組み（C）で欧文の行は1文字ずつ積まず、行ごと90度倒す（和文縦組みの通例）。
- **表紙の作品画像は絶対にトリミングしない**（`drawContained`）。扱う作品はA1〜A4の縦長が大半で、
  `drawCovered`（塗り足しまで敷き詰める）を使うと顔や構図が切れる。表紙では使わないこと。
  レイアウトは「先に作品の寸法を `fitBox()` で決め、そこから枠を組む」順で書く。逆順にすると
  縦長の作品で余白が大きく空く。
- **会期・会場は表紙に入れない**。実物の表紙も入っていないものが多く、面が窮屈になるため。
- 見出しは `drawCoverHeadline()` を通す。**長い和文タイトルは級数を落とす前に折り返す**
  （1行に押し込むと「「シグルイ」メタルキャンバスアート展」のようなタイトルが極端に小さくなり、
  表紙の主役にならない）。`maxHeight` を渡すとその高さに収まるまで級数を落とす。
- 縦組み（C）は行の長さがそのまま高さになるので、最長行が版面に収まる級数を先に計算する。
  固定級数のままだと長いタイトルが下にはみ出して切れる。
- 表紙の作品は天地中央ではなく**地寄せ**にする（中央に置くと宙に浮いて見える）。
- 旧: 枠からはみ出す場合は級数を落として必ず収める
  （長い和文タイトルで切れていた不具合の対策）。
- Fは版元からロゴのみ支給で作品画像が使えない案件用。IPロゴは別途アップロードする（`state.ipLogo`）。
  IPロゴ・×・GAAATロゴは1つの組みとして総高を出してから天地中央に置く（要素ごとに置くと間延びする）。
- GAAAT面下部の4つのQR（web / EC / X / Instagram）は毎回同じなので `leaflet/assets/qr-*.png` に
  同梱し、`BRAND_QR_SLOTS` から読むだけにしてある。差し替えUIは持たない（案件ごとに変わらないため）。
  変える必要が出たらこの画像を置き換える。
- ドライブは「フォルダを読む」と「画像を取得する」を必ず続けて行うので、ボタンは分けずに
  `loadDriveFolderBtn` 一つにまとめ、読み込み成功後そのまま `fetchAllArtImages()` まで走らせる。
  `loadDriveFolder()` は見つかった件数を返し、0件・失敗時は呼び出し側が止まる。
- 「How to buy」のマーカーは表紙のアクセント色（`c.accent`）に追従する。
- 自動選択は `classifyCoverTemplate()`。表紙画像を48pxに縮めて地の明るさと最大彩度を測り
  （`samplePalette()`）、暗ければ `condensed`、彩度が高ければ `verticalJa`、それ以外は `arch`、
  画像が無くIPロゴがあれば `lockup` に振る。**運用しながら閾値を調整する前提のたたき台**で、
  プルダウンを手で変えると自動選択はオフになる。
- 縦組みは `drawVerticalText()`。`VERTICAL_ROTATE` にある約物だけ90度倒し、他は正立で送る。
- 会期行の字送りは `drawTrackedText()`。既存表紙が字間を空けた組みなので、それに寄せている。

### 参照範囲の限界

パターン化に使えたのは **17案件中6案件**（syoyo / BECK / サイボーグ009 / しゅごキャラ! /
ZEENCHIN / ウルトラマン）。残りはドライブ上のPDFが100MB〜2.6GBあり取得できなかった。
軽量PDFかJPEGで書き出したものを1フォルダにまとめれば取り込めるので、パターンは今後増減しうる。
