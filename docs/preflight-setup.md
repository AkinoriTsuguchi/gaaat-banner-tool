# 入稿チェックツール 準備手順（Mac）

入稿チェックを回す人のMacで、**最初に1回だけ**やる作業。所要 10〜15分。
2回目以降は何もしなくていい。

やることは2つだけ。

1. 「パソコン版 Google ドライブ」を入れる
2. 入稿フォルダに **ショートカット** を付ける（← ここを飛ばすと動きません）

---

## なぜ必要か

Illustrator のスクリプトは、**Finder で開けるフォルダしか扱えない**。
ブラウザで見ている Google ドライブは Finder からは見えないので、そのままでは
スクリプトが入稿ファイルを見つけられない。

「パソコン版 Google ドライブ」を入れると、Google ドライブの中身が
**Finder の中に普通のフォルダとして出てくる**。中身の実体はクラウドにあって、
開いたときだけ降りてくるので、ディスクは食わない。

---

## 手順1: 「パソコン版 Google ドライブ」を入れる

1. ブラウザで **https://www.google.com/drive/download/** を開く
2. **「パソコン版ドライブをダウンロード」** を押す（`GoogleDrive.dmg` が落ちてくる）
3. ダウンロードした `GoogleDrive.dmg` をダブルクリック
4. 出てきたウィンドウで **`Google Drive.app` を `Applications` フォルダにドラッグ**
5. `Applications` の中の **Google Drive** をダブルクリックして起動
6. 「開いてもよろしいですか？」→ **開く**
7. 途中で **「システム機能拡張がブロックされました」** と出たら:
   - **システム設定 › プライバシーとセキュリティ** を開く
   - 下のほうにある **「許可」** ボタンを押す
   - Mac の再起動を求められたら再起動する
8. **会社の Google アカウントでログイン**
9. 画面右上のメニューバーに ▲ のドライブアイコンが出れば成功

### 確認

Finder を開くと、左のサイドバーに **「Google Drive」** が増えている。
クリックすると中に **「マイドライブ」** がある。

---

## 手順2: 「GAAAT」フォルダにショートカットを付ける（重要・1回だけ）

ここが一番つまずくところ。

### 「共有ドライブ」と「共有アイテム」は別物

パソコン版ドライブを入れると、Finder に **マイドライブ** と **共有ドライブ** の
2つが出てくる。ここで紛らわしいのが、**この2つに入らない3つ目の場所**があること。

| 場所 | Finder に出るか |
|---|---|
| マイドライブ | ○ 出る |
| 共有ドライブ（チーム用の箱） | ○ 出る |
| **共有アイテム**（人から共有されただけのフォルダ） | **× 出ない** |

GAAAT の入稿データは **3つ目の「共有アイテム」**に入っている。
`GAAAT` フォルダそのものが他の人の持ち物で、そこから下がぶら下がっているため、
「共有ドライブ」が見えていても Finder には出てこない。

だから、マイドライブにショートカットを置いて**見えるようにする**必要がある。

### 一番上の「GAAAT」フォルダに1回だけ付ける

案件ごとに付ける必要はない。**一番上の `GAAAT` フォルダに1回付ければ、
その下の案件は全部まとめて見えるようになる。**

1. **ブラウザ**で Google ドライブを開く
2. 左メニューの **「共有アイテム」** をクリック
3. **`GAAAT`** フォルダを **右クリック**
4. **「整理」→「ショートカットを追加」**
   （メニューが違う場合は **「ドライブにショートカットを追加」**）
5. 出てきたダイアログで、上のタブの **「すべての場所」** をクリック
   - 最初に開く **「候補」** タブは最近使ったフォルダの一覧なので、マイドライブは出てこない
   - 検索欄に「マイドライブ」やURLを入れても出てこない。あれはフォルダを**名前で**探す欄
6. 一覧の **「マイドライブ」** を **1回だけ**クリックして選択
   （ダブルクリックすると中に入ってしまう）
7. 右下の **「追加」** が青くなるので押す

置き場所はマイドライブの直下でなくてよい。マイドライブの中ならどこでも Finder から辿れる。
「追加」がグレーのままなのは、場所が選ばれていないとき。

### 確認

Finder で **Google Drive › マイドライブ › GAAAT** を開くと、そこから下は
ブラウザで見ているのと同じ構造になっている。パトレイバーの入稿フォルダなら:

```
マイドライブ / GAAAT / クリエイティブ制作 / 格納先 / 制作完了
  / 033_パトレイバー / R228_機動警察パトレイバー_リーフレット / 最新制作物
```

この `最新制作物` の中に

```
[ol前]R228_機動警察パトレイバー_リーフレット.ai
[ol後]R228_機動警察パトレイバー_リーフレット.ai
R228_機動警察パトレイバー_リーフレット.pdf
old/
```

が見えていれば **準備完了**。入稿チェックで選ぶのはこの `最新制作物` フォルダ。

## おすすめ（任意）: 先にダウンロードしておく

入稿ファイルは **1本 425MB** ある。初回に Illustrator で開くとき、
クラウドから降りてくるのを数分待つことになる。

待ちたくない場合は、Finder で入稿フォルダを **右クリック → 「オフラインで使用可能にする」**。
先にまとめて落としておける（1案件あたり 1.2GB ほどディスクを使う）。
チェックが終わったら、同じメニューから元に戻せる。

---

## うまくいかないとき

| 症状 | 対処 |
|---|---|
| Finder に Google Drive は出るが、マイドライブも共有ドライブも空 | **アプリが起動していない**。`Applications` の Google Drive を起動してログインする。メニューバーに ▲ アイコンが出ていれば動いている |
| Finder のサイドバーに Google Drive が出ない | Google Drive アプリが起動しているか確認（メニューバーに ▲ アイコン）。無ければ `Applications` から起動 |
| ショートカットのダイアログにマイドライブが出ない | 上のタブが「候補」になっている。**「すべての場所」** タブに切り替える |
| マイドライブに GAAAT が無い | 手順2のショートカットを付け忘れている。ブラウザの「共有アイテム」で `GAAAT` を右クリック →「整理」→「ショートカットを追加」 |
| 「共有ドライブ」は見えるのに入稿フォルダが無い | 入稿データは「共有ドライブ」ではなく「共有アイテム」にある。手順2が必要 |
| フォルダはあるが中身が空に見える | 同期中。メニューバーのドライブアイコンを押して進捗を確認 |
| 「システム機能拡張がブロックされました」から進めない | システム設定 › プライバシーとセキュリティ で「許可」→ Mac を再起動 |
| 会社の管理でインストールできない | 情シスに「パソコン版 Google ドライブ（Google Drive for desktop）」の許可を依頼。どうしても無理なら、案件ごとに3ファイルを手でダウンロードして、そのフォルダを指定する運用でも動く（毎回 1.2GB） |
